# Безопасность и приватность

Это неофициальный порт старого клиента, а не аудит безопасности Minecraft Galaxy.

## Учётные данные

В 1.6.7 менеджер сохраняет логины, названия карточек и публичные данные
персонажей. Прежняя галочка сохранения логина заменена списком аккаунтов.
Пароль не записывается в UserDefaults и не передаётся аргументом командной
строки: для передачи игровому процессу используется одноразовый локальный FIFO.
Это не исключает нахождения пароля в памяти процесса и не изменяет сетевой
протокол официального клиента.

`native-replacements/src/nixspecific_arm64.c` реализует совместимость со старым
JNI-вызовом авторизации: читает `IOPlatformUUID` Mac и формирует данные из
идентификатора компьютера, логина и пароля. Код использует MD5 и фиксированную
XOR-маску старого формата. **Это не современное защищённое шифрование.**
Не следует воспринимать открытый исходный код как гарантию безопасности
старого протокола или использовать один пароль для разных сервисов.

## Публичные профили в 1.6.7

При добавлении аккаунта интерфейс сообщает об отправке ника форуму MCGL.
Уровни и профессия запрашиваются по HTTPS на `forum.minecraft-galaxy.ru`,
без cookies, авторизации, паролей и аппаратных идентификаторов. Редиректы
не разрешены, проверка TLS-сертификата не отключается. HTML не исполняется;
внешние изображения/ссылки не загружаются. Размеры ответа и inline-аватара,
параллельность запросов и время ожидания ограничены.

Кэш профиля — не подтверждение входа в игровой аккаунт. Ник и статистика
являются локальными персональными данными: не публикуйте настройки лаунчера
целиком. Удаление карточки удаляет её кэш из списка, но не затрагивает игровой
аккаунт. При удалении карточки удаляется также её локальный сохранённый пароль.

## Локальное сохранение паролей в 1.6.7

Сохранение выключено по умолчанию и включается галочкой отдельно для выбранного
сохранённого аккаунта. При первом включении показано пояснение с возможностью
отмены. Галочка не отправляет пароль на сервер для проверки: сохранённый пароль
может оказаться неверным. Снятие галочки удаляет запись этого аккаунта.

`MCGLPasswordStore.swift` использует [AES-GCM из Apple CryptoKit](https://developer.apple.com/documentation/cryptokit/aes/gcm)
с отдельным случайным 256-битным ключом на установку и новым nonce при каждой
записи. UUID аккаунта и нормализованный ник включены в authenticated data;
перенос шифротекста на другую карточку отклоняется. Папка
`~/Library/Application Support/Minecraft Galaxy ARM64/Credentials/` имеет права
700, обычные файлы — 600; проверяются владелец, размер, тип и ссылки. Запись
заменяется атомарно, ключ не пересоздаётся молча поверх существующих записей.
Ошибки не содержат пароль, ключ или содержимое файла.

**Ключ находится рядом с файлами паролей. Это НЕ защита от программ,
работающих с доступом к файлам данного пользователя, root или копии всей папки.**
Связка ключей и мастер-пароль не используются, гарантии системного credential
vault нет. Такой способ выбран для удобства по явному запросу автора порта.
Не передавайте папку Credentials и её резервные копии другим людям; не
включайте её в отчёты или релиз. `.gitignore` исключает эти файлы дополнительно.
Удаление записи — не гарантированное стирание с SSD, снапшотов и резервных копий.
Заменить пароль на сервере следует отдельно, если данные уже могли попасть к третьим лицам.

Смена карточки очищает поле перед загрузкой пароля другой карточки. Ручное
изменение логина снимает выбор карточки и очищает пароль, не удаляя прежнюю
сохранённую запись. Ни менеджер, ни хранилище не запускают новый сетевой вход.

## Загрузка клиента

В 1.6.7 установщик обращается к зеркалам `f1.mcgl.ru`, `f3.mcgl.ru`, `f2.mcgl.ru`
по HTTP и проверяет файлы по MD5 из полученного списка. Это проверка соответствия
списку, **не криптографическое подтверждение его подлинности**: HTTP и MD5
не защищают от активной подмены списка и файлов. Автоматическое обновление
не следует путать с подписанным каналом доставки.

Проверка версии лаунчера обращается по HTTPS только к GitHub API репозитория
`prilepv/mcgl-arm64`. DMG берётся из соответствующего GitHub Release. Если API
возвращает SHA-256 asset digest, лаунчер проверяет его перед сохранением файла.
Обновление не запускается и не устанавливается скрытно: DMG сохраняется в папку
«Загрузки» и открывается для ручной установки пользователем.

## Подпись приложения

Релиз 1.6.7 подписан ad-hoc и не нотарифицирован Apple. SHA-256 опубликованного
DMG позволяет сравнить файл с релизом, но не заменяет Developer ID,
нотариализацию или независимую проверку исходников и сборки.

## Сообщения о проблемах

Не публикуйте реальные пароли, токены, аппаратные идентификаторы, полный профиль
игры или неотредактированные журналы. Для обычных ошибок используйте Issues.
Не выкладывайте в публичный Issue действующие секреты или подробности
эксплуатации уязвимости до согласования безопасного способа сообщения.
