# Значки профессий Minecraft Galaxy

Оригинальные изображения проекта, взятые 6 сентября 2026 года из
[официальной вики «Профессии»](https://forum.minecraft-galaxy.ru/wiki/42).
Правообладатель — Project Galaxy / авторы изображений; лицензия MIT к этим
семи изображениям не применяется. Используются для обозначения профессий
MCGL в неофициальном лаунчере, без изменения изображений.
