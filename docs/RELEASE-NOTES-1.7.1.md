# Minecraft Galaxy ARM64 1.7.1 — исправление осадков

Небольшой выпуск исправлений на основе локальной сборки 189.

## Что исправлено

- Устранена известная ошибка отрисовки дождя и снега: в столбце осадков
  непосредственно у камеры возникали некорректные координаты (`NaN`),
  из-за которых клиент мог завершить игровую сессию. Остальная геометрия
  осадков и проверки корректности Core-рендера сохранены.
- Освещённый текст на табличках теперь использует упорядоченную пакетную
  отрисовку. Сохраняются символы, их порядок, матрицы, освещение и материалы.
  Пользовательские эффекты и несовместимые случаи используют прежний путь.
- В офлайн-вкладке «Изменения» добавлено краткое описание 1.7.1.

Путь отрисовки моделей существ возвращён к варианту build 189.
Экспериментальное объединение их геометрии из build 190 не включено.
Новых численных результатов игрового FPS для этого выпуска нет:
автоматические проверки не заменяют проверку всех локаций и устройств.

## Как обновиться

Нажмите в старом лаунчере «Проверить обновления» или скачайте
`Minecraft-Galaxy-ARM64-Bootstrap-1.7.1.dmg` из GitHub Releases.
Закройте игру и лаунчер, откройте DMG и замените приложение в «Программах».
При следующем запуске установщик обновит игровые библиотеки и патчи.

Аккаунты, сохранённые пароли, профиль игры и настройки сохраняются.
Удалять профиль или отдельно устанавливать Java не нужно. Обновление применимо
как к публичной 1.7.0, так и к локальным сборкам 188–190.

Требования прежние: Apple Silicon, macOS 14+, интернет и аккаунт MCGL.
Java 21 ARM64 включена; оригинальные игровые JAR и ресурсы скачиваются с зеркал MCGL.
Подпись ad-hoc, без Developer ID и нотариализации Apple. DMG не обходит Gatekeeper.
