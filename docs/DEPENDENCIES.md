# Зависимости и происхождение снимка 1.6.4

История разработки до публикации не импортируется: рабочая папка порта не была
единым git-репозиторием. Первый коммит — снимок отобранных исходников, а не
реконструированная история версий 1.0–1.6.4.

Лицензия MIT в корне относится к собственному коду порта. Она не заменяет
лицензии файлов в `third-party`, встроенной Java и других сторонних компонентов.
В изменённых файлах LWJGL сохранены исходные copyright/license headers.

- Основа: [kittylyst/lwjgl2](https://github.com/kittylyst/lwjgl2).
- Коммит: `bae8fa5001cdeb144dd2b54e26fd896ad91ddef8`.

Overlay включает Java/Cocoa-изменения, ARM64-настройки native-сборки,
ограничитель кадров, профилировщик и **изменённый сгенерированный `GL11.java`**.
Последний обычно игнорируется upstream Git, поэтому опубликован явно.
Нельзя перегенерировать его поверх патча без повторного применения изменений.
Это набор полных файлов для наложения на конкретный upstream, а не полный форк
всей библиотеки. Сторонний код LWJGL не перелицензируется в MIT.

## ASM и инструменты сборки

Патчеры 1.6.4 собраны с `asm-debug-all.jar`, в манифесте которого указано
`Implementation-Version: 4.0_RC1`. Они используют старый visitor API.
Не подменяйте этот JAR на современный ASM без адаптации и повторных тестов.
ASM — BSD 3-Clause, [upstream](https://asm.ow2.io/).

Отдельно генератор upstream LWJGL использует свой набор ASM-зависимостей.
Это не обязательно та же версия, что у патчеров клиента.
Для исторической сборки также использовались Apache Ant 1.10.15,
Apple Command Line Tools (Swift/Clang/SDK), JDK 8 и инструменты сборки native
зависимостей. Они не включены в этот git-репозиторий.

## Что не входит в исходники

Официальные JAR, текстуры, музыка и другие ресурсы MCGL; декомпилированные
классы клиента; профили игроков; журналы; исполняемые файлы; локальные кэши.
Упоминания имён классов в патчерах нужны для совместимости и не означают
публикацию исходников оригинального клиента.

Иконка, которую использует исторический скрипт сборки, берётся из старого
локального app bundle. В этот снимок она не включена; для своей сборки
нужно отдельно подготовить разрешённую к использованию иконку.
