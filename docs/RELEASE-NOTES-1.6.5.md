# Minecraft Galaxy ARM64 — Bootstrap 1.6.5

Первый релиз с обновлённым интерфейсом, раздельной настройкой памяти и встроенной
проверкой новых версий лаунчера.

## Установка

Скачайте `Minecraft-Galaxy-ARM64-Bootstrap-1.6.5.dmg` из файлов релиза,
откройте образ и перенесите **Minecraft Galaxy ARM64** в «Программы».

Требуется Mac с Apple Silicon и macOS 14 или новее. Java и ARM64-библиотеки уже
находятся внутри приложения. У сборки пока нет Developer ID и нотариализации
Apple, поэтому при первом запуске macOS может показать предупреждение о
непроверенном разработчике.

## Лаунчер

- Новый интерфейс в стиле проекта с отдельными вкладками «Играть», «Настройки»
  и «Журнал», собственным фоном и новой иконкой ARM64-порта.
- Начальная память Java (Xms) и максимальная память (Xmx) теперь задаются
  независимо. Начальное значение автоматически ограничивается максимальным.
- Диагностика графики выключена по умолчанию; VBO/VAO и G1GC включены по
  умолчанию для новой установки. Существующие сохранённые значения учитываются.
- Лаунчер проверяет последний GitHub Release `prilepv/mcgl-arm64`. Доступный DMG
  скачивается в «Загрузки» и открывается для явной ручной установки. Само
  запущенное приложение не перезаписывается.

## Исправление прозрачных блоков

Артефакт с прозрачными гранями возникал, когда штатная настройка клиента
`alphaSort` была выключена. VBO не являлся причиной: ошибка повторялась и на
старом display-list пути.

В 1.6.5 патчер проверяет точное поле настройки, метод-флаг и вызов из рендера
чанков, после чего включает существующую сортировку прозрачных четырёхугольников
по умолчанию. Для профиля от старой версии строка `alphaSort:false` один раз
меняется на `alphaSort:true` во время обновления порта. После миграции настройка
остаётся обычной пользовательской опцией и не перезаписывается при каждом старте.

Быстрый QuadSort из 1.6.0, VBO/VAO и запасной display-list путь сохранены.
Геометрия, текстуры и качество графики не снижались.

## Проверка

Исходники компилируются для ARM64/macOS 14. Проверены настройки обновлятора,
миграция профиля, структура байткода прозрачности и прежний набор тестов
частиц, анимаций, освещения, VBO, QuadSort и ограничения FPS. Это не заменяет
проверку реального запуска и графики на нескольких моделях Mac.

История предыдущих оптимизаций: [заметки к 1.6.4](RELEASE-NOTES-1.6.4.md).
