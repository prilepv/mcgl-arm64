# Minecraft Galaxy ARM64 1.7.2 — оптимизация отрисовки

Выпуск на основе принятой локальной сборки 196. Графические настройки,
дальность, разрешение, шрифты и порядок прозрачной геометрии сохранены.

## Что изменилось

- Совместимые материалы мира объединяются в более крупные упорядоченные
  пакеты. Текстурные массивы сокращают переключения между подходящими
  текстурами, сохраняя фильтрацию, mip-уровни и исходное изображение.
- Расширено размещение исходной геометрии на GPU: меньше разрывов между
  страницами и компактные теги матриц в свободном байте формата.
- Ускорена подготовка геометрии; совместимые части моделей объединяются
  при их компиляции, без перепаковки всей модели каждый кадр.
- Уменьшены лишние переключения графического состояния. Для проходов,
  в которых исходная игра уже выключила освещение, используются облегчённые
  встроенные шейдеры; освещённые проходы и пользовательские эффекты сохранены.
- В офлайн-вкладке «Изменения» добавлена краткая запись 1.7.2.

GPU-кэш исходной геометрии ограничен 320 МиБ; кэш текстурных массивов —
64 МиБ и 32 страницами. Это отдельные бюджеты, не общий расход памяти игры.
На менее ёмких драйверах выбирается меньшая таблица матриц; неподдерживаемые
текстуры и состояния используют совместимый прежний путь. Сортировка
прозрачности, планировщик мира и исправление дождя/снега из 1.7.1 сохранены.

Сборка 196 прошла пользовательскую приёмку. Нового численного замера
игрового FPS для этого выпуска нет; фиксированный прирост не обещается. Автоматические
проверки сравнивают пиксели, глубину и состояние, но не заменяют проверку
всех миров, эффектов и компьютеров. Подробности — в [проверках](TESTING.md).

## Как обновиться

Нажмите в старом лаунчере «Проверить обновления» или скачайте
`Minecraft-Galaxy-ARM64-Bootstrap-1.7.2.dmg` из GitHub Releases.
Закройте игру и лаунчер, откройте DMG и замените приложение в «Программах».
При следующем запуске установщик обновит необходимые библиотеки и патчи.

Аккаунты, сохранённые пароли, профиль и настройки находятся вне приложения
и сохраняются. Удалять профиль или отдельно устанавливать Java не нужно.
Локальная сборка 196 с номером 1.7.1 также видит новый номер релиза;
её игровой код совпадает с 1.7.2.

Требования прежние: Apple Silicon, macOS 14+, интернет и аккаунт MCGL.
Java 21 ARM64 включена; оригинальные игровые JAR и ресурсы скачиваются
с зеркал MCGL. Подпись ad-hoc, без Developer ID и нотариализации Apple.
DMG и контрольная сумма не обходят Gatekeeper.
