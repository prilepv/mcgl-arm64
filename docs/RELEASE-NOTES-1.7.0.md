# Minecraft Galaxy ARM64 1.7.0 — новый графический фундамент

Публичный выпуск объединяет принятую модернизацию после 1.6.7 и новую вкладку
«Изменения». Промежуточные 1.6.8–1.6.19 были локальными этапами разработки,
а не отдельными публичными релизами.

## Коротко

- Встроенная Java 21 ARM64, LWJGL 3 и GLFW вместо прежней основы Java 8 / LWJGL 2.
- Игровая отрисовка на OpenGL 4.1 Core: шейдеры, VAO/VBO и индексированные меши.
- Пакетная отправка соседних чанковых мешей и текста; исправлен чанковый кэш.
- Нативный полноэкранный режим macOS: отдельный Space, зелёная кнопка и F11.
- Вкладка «Изменения» с короткими описаниями 1.7.0 и прошлых 1.6.4–1.6.7.

## Что изменилось для игрока

Рендер объединяет совместимые соседние вызовы, сохраняя исходные матрицы,
порядок, игровой планировщик и локальную сортировку прозрачности. Геометрия
не перепаковывается при каждом повороте камеры. Исправлено нерациональное
занятие GPU-страниц разными форматами; небольшие одиночные меши возвращаются
в пакетную отрисовку после освобождения места без пересборки мира.

Fullscreen использует механизм macOS Spaces, без переключения видеорежима
монитора. Состояние игры синхронизируется с зелёной кнопкой и F11, а система
восстанавливает оконный размер и положение после выхода.

История релизов встроена в лаунчер: интернет нужен только после нажатия
«Подробнее на GitHub». Возле новой вкладки есть отметка непрочитанных изменений.
Исторические описания сокращены отдельно; длинные тексты старых релизов
не изменяются. ⌘1–⌘4 сохранены, ⌘5 открывает «Изменения».
Номер установленной версии берётся из самого приложения.

## Обновление

Скачайте `Minecraft-Galaxy-ARM64-Bootstrap-1.7.0.dmg` и проверьте прилагаемый
SHA-256 при необходимости. Закройте игру и лаунчер, перенесите приложение
в «Программы» с заменой. Старые лаунчеры с GitHub-обновлятором предлагают
этот же DMG; установка остаётся явной и ручной.

Аккаунты, сохранённые пароли, настройки памяти/FPS и профиль игры сохраняются.
Установщик обновляет исходные игровые JAR и компоненты порта, затем проверяемо
применяет Core-патчи. Это не требует удаления профиля или отдельной установки Java.
Если уже установлена локальная 1.7.0, ту же версию скачайте вручную.

Требования: Apple Silicon, macOS 14+, интернет для получения официального
клиента и аккаунт MCGL. Java 21 уже включена. Сборка имеет ad-hoc подпись,
без Developer ID и нотариализации Apple; упаковка в DMG не обходит Gatekeeper.
[Установка и безопасность](../README.md#скачать-и-запустить), [приватность](../SECURITY.md).

## Проверки и границы

Принятый игровой вариант проверялся пользователем; после исправления кэша
подтверждено восстановление FPS. Автоматические проверки сравнивают пиксели,
глубину, порядок, исходные алгоритмы, ресурсы и поведение окна. В специальной
сцене с 1 048 576 вершинами исправление кэша сократило 2048 одиночных вызовов
до 65 пакетных при побитово одинаковой картинке. Это не игровой FPS.

Точные прогоны выпуска перечислены в [TESTING.md](TESTING.md).
Производительность зависит от сцены, настроек и Mac; гарантий конкретного FPS,
эквивалентности всех сцен или проверки на всех устройствах нет.
Слой совместимости legacy ещё присутствует. Полное удаление fixed-function
кода, многопоточное построение чанков и финальная оптимизация всей карты
не объявляются завершёнными: [карта модернизации](modernization/README.md).

Точные зависимости: [DEPENDENCIES.md](DEPENDENCIES.md).
Исходники по тегу включают собственные компоненты и изменённые сторонние файлы,
но не оригинальные игровые JAR, ресурсы, пользовательские профили или личные
материалы автора. Сборка требует подготовленных зависимостей; побайтовая
воспроизводимость DMG из чистого клона на другом Mac не заявляется.
