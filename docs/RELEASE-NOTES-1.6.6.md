# Minecraft Galaxy ARM64 1.6.6 — Новая орбита

Тёмный сине-фиолетовый лаунчер с космическим фоном, новой иконкой и боковым
меню. Запуск и остановка игры теперь на одной кнопке. Игровые оптимизации
и исправление прозрачных блоков из 1.6.5 сохранены.

## Что изменилось

- Новое оформление: статический космический фон, тёмные карточки и мягкие
  сине-фиолетовые акценты. Анимированного фона и дополнительных кадровых таймеров нет.
- Иконка приложения — куб с орбитой без квадратной подложки. Для GitHub и
  форума сохранён отдельный вариант с тёмным фоном.
- Боковая навигация «Играть», «Настройки», «Журнал»; быстрые клавиши ⌘1 / ⌘2 / ⌘3.
- Начальная и максимальная память остаются раздельными. Настройки памяти
  и производительности сгруппированы в отдельные карточки.
- Одна кнопка меняет состояние: «Запустить игру» → «Подготовка…» → «Запуск…»
  → «Остановить игру» → «Остановка…». Повторные нажатия во время подготовки,
  запуска и остановки заблокированы. Enter не останавливает работающую игру.
- После ошибок подготовки/запуска кнопка возвращается в исходное состояние.
- Убраны повторяющиеся заголовки. Исправлен контраст всех четырёх подписей
  галочек и отступы внутри журнала. Состояние игры видно на любой странице.

## Обновление с 1.6.5

1. Откройте установленную 1.6.5 и нажмите «Проверить обновления».
2. Выберите «Скачать DMG»; лаунчер сохранит образ в «Загрузки» и откроет его.
3. Закройте игру и лаунчер.
4. Перетащите приложение из образа в «Программы» с заменой.
5. Откройте приложение из «Программ» и проверьте номер 1.6.6 в боковом меню.

Формат GitHub Releases и механизм скачивания совместимы с 1.6.5. Настройки,
сохранённый логин и профиль игры остаются на месте. Маркер версии **игровых
патчей** намеренно остаётся 1.6.5: изменение оформления не должно повторно
патчить клиент и сбрасывать пользовательскую настройку сортировки прозрачности.
Если за это время обновятся официальные файлы MCGL, штатная проверка клиента
по-прежнему обработает их отдельно.

## Требования и ограничения

Apple Silicon, macOS 14 или новее. ARM64 Java 8 уже включена.
Сборка по-прежнему подписана ad-hoc, без Developer ID и нотариализации Apple.
DMG и SHA-256 не отменяют предупреждения Gatekeeper.
Проверки и их границы: [TESTING.md](https://github.com/prilepv/mcgl-arm64/blob/main/docs/TESTING.md).

Это релиз интерфейса. Новых изменений рендерера и обещаний прироста FPS нет.
История предыдущей версии: [1.6.5](https://github.com/prilepv/mcgl-arm64/blob/main/docs/RELEASE-NOTES-1.6.5.md).
