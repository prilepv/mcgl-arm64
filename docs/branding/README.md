# Иконки Minecraft Galaxy

В 1.8.0 используется аметистовый куб. В верхней панели лаунчера он отображается с прозрачным фоном. В Finder и Dock у лаунчера и игры одинаковая иконка с белой скруглённой подложкой и тенью под кубом.

- [Иконка Finder и Dock](project-icon-macos.png)
- [Символ для интерфейса](../../native-launcher/Assets/app-icon-symbol.png)

`tools/ComposeAppIcon.swift` собирает системную иконку из прозрачного символа при упаковке приложения.
