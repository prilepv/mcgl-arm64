# 1.7.3 — совместимость с обновлённым MCGL

12 октября 2026 · build 197 · macOS 14+ · Apple Silicon

После обновления официального клиента старые версии порта могли перестать
запускать игру с сообщением:

```text
Expected one Display.setParent sequence, found 0
```

Официальный клиент изменил имена классов и часть кода отрисовки, поэтому
прежние патчи больше не находили ожидаемые участки. Это несовместимость порта
с обновлением, а не повод удалять аккаунты, профиль игры или переустанавливать Java.

## Что исправлено

- Восстановлена подготовка и запуск обновлённого официального клиента.
- Оконный патч находит операции по структуре байткода, а не по старым смещениям.
- Добавлена проверенная адаптация новых имён классов и методов. Временные имена
  используются только при подготовке; в установленный клиент возвращаются
  официальные имена. Исходные игровые файлы не распространяются вместе с портом.
- Сохранены обновлённые правила выбора проходов мира и сортировки прозрачности.
- Контрольные суммы и проверки патчей не отключены. Неизвестный будущий клиент
  останавливает подготовку с понятным сообщением, не заменяя установленный профиль.

Сохранены оптимизации **1.7.2**, исправление осадков, Java 21 ARM64, LWJGL 3,
OpenGL 4.1 Core, нативный fullscreen macOS, аккаунты и настройки. Нового
обещания прироста FPS нет: это выпуск совместимости, а не новый этап оптимизации.

## Как обновиться

1. Нажмите «Проверить обновления» → «Скачать DMG» или откройте
   [релиз 1.7.3](https://github.com/prilepv/mcgl-arm64/releases/tag/v1.7.3).
2. Закройте игру и лаунчер. Откройте DMG и замените приложение в «Программах».
3. Запустите **1.7.3** и дождитесь подготовки официального клиента.

Профиль игры, аккаунты, сохранённые пароли и настройки находятся вне приложения
и сохраняются. Удалять их не нужно. Установка обновления приложения ручная;
официальные файлы игры загружаются с зеркал MCGL отдельно.

## Проверка и ограничения

Выпуск основан на **build 197**, принятой пользователем после игровой проверки.
Проверены прежний и обновлённый официальные JAR: обратимость адаптации,
сортировка прозрачности, применение патчей настоящим установщиком, разрешение
ссылок на классы/поля/методы и безопасный отказ на неизвестном клиенте.
Подробности и границы проверок — в [TESTING.md](TESTING.md).

Это не гарантия работы любых будущих обновлений MCGL или отсутствия ошибок
во всех игровых сценах. Если официальный клиент снова изменится, может
понадобиться новая версия порта.

Нужны Apple Silicon (M1 и новее), macOS 14+, интернет и аккаунт MCGL.
Java встроена. Подпись приложения **ad-hoc**, без Developer ID и нотариализации
Apple; SHA-256 не отменяет проверки macOS. Не отключайте защиту системы целиком.
[Безопасность и приватность](../SECURITY.md).
