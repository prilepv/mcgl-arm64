# Лаунчер 1.7.3

Пять настоящих страниц AppKit, снятых с отдельного окна инструментом
`tools/CaptureLauncherScreenshots.swift`: Играть, Аккаунты, Настройки, Журнал
и Изменения. Размер каждого PNG — 2000×1440.

DemoMiner и DemoBuilder — вымышленные аккаунты. Уровни, карточки и журнал
заданы тестовыми данными; поля паролей пусты. Инструмент не выполняет сетевые
запросы, не авторизуется в игре и не использует пользовательский профиль.
Это изображения интерфейса, не замеры игрового FPS.
