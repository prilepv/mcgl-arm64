# Предпросмотр интерфейса 1.6.7

Изображения получены системным захватом отдельного AppKit-окна лаунчера через
`tools/CaptureLauncherScreenshots.swift`, а не генерацией макета. Размер —
2000 × 1440 (2×). Настройки изолированы:
DemoMiner и DemoBuilder — демонстрационные аккаунты, уровни — тестовые.
Настоящие логины, пароли и аватары пользователей в этих PNG отсутствуют.

- `launcher-play.png` — вход, сохранение пароля по желанию и компактная карточка с ником, аватаром и уровнями.
- `launcher-accounts.png` — менеджер с двумя демонстрационными персонажами.
- `launcher-settings.png` — игровые параметры, не изменявшиеся в 1.6.7.
- `launcher-log.png` — журнал с явно обозначенным демонстрационным текстом.

Это предпросмотр интерфейса, не доказательство игрового входа или FPS.
Скриншоты 1.6.5 и 1.6.6 сохранены в прежних папках.
