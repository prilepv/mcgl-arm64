# Скриншоты лаунчера 1.6.6

Реальные снимки окна macOS: «Играть», «Настройки» и «Журнал».
В кадрах нет введённого логина, пароля или журнала игровой сессии.
Изображения предыдущей версии сохранены по прежним адресам.

Прямые URL для вставки на форум:

- [Играть](https://raw.githubusercontent.com/prilepv/mcgl-arm64/main/docs/screenshots/1.6.6/launcher-play.png)
- [Настройки](https://raw.githubusercontent.com/prilepv/mcgl-arm64/main/docs/screenshots/1.6.6/launcher-settings.png)
- [Журнал](https://raw.githubusercontent.com/prilepv/mcgl-arm64/main/docs/screenshots/1.6.6/launcher-log.png)
- [Иконка с белой подложкой и прозрачными внешними углами, 220 × 220](https://raw.githubusercontent.com/prilepv/mcgl-arm64/main/docs/forum-icon-1.6.6-macos.png)

Белая подложка нарисована AppKit, без нейросетевой маски. Для иконки используйте
новый адрес выше: в теге `v1.6.6` остались первоначальные изображения.
Скриншоты вкладок сохранены от первоначальной 1.6.6: прозрачный символ в
боковом меню остаётся таким же. Белая плашка применяется только к системной
иконке в Dock/Finder и отдельной форумной картинке.
Предыдущий тёмный вариант сохранён как `docs/forum-icon-1.6.6-rounded.png`.
