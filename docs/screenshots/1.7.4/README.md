# Лаунчер 1.7.4

Пять настоящих страниц AppKit, снятых инструментом
`tools/CaptureLauncherScreenshots.swift`: Играть, Аккаунты, Настройки, Журнал
и Изменения. Размер каждого PNG — 2000×1440.

Аккаунты DemoMiner и DemoBuilder, уровни и журнал вымышленные; поля паролей
пустые. Инструмент снимает только отдельное окно, не авторизуется в игре,
не выполняет сетевые запросы и не использует пользовательский профиль.
