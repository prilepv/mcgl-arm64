# 1.7.4 — поддержка нового официального клиента

1 ноября 2026 · build 198 · macOS 14+ · Apple Silicon

После очередного обновления официального MCGL версия 1.7.3 могла завершить
подготовку сообщением «официальный клиент MCGL изменился и пока не поддерживается».
Новый официальный файл был загружен корректно, но ещё не входил в проверенные
профили порта. Версия 1.7.4 восстанавливает его подготовку и запуск.

## Изменения

- Добавлен отдельный проверенный профиль ноябрьского клиента: новые имена
  классов и методов адаптированы к существующим патчам.
- Сохранена поддержка исходного и октябрьского официальных клиентов.
- Обновлены точные проверки изменённых методов. В разобранных участках менялись
  ключи шифрования строк; после декодирования инструкции и текст совпадают.
- Выбор профиля передаётся явно через все стадии подготовки; временные имена
  восстанавливаются до установки клиента.
- Сохранены оптимизации 1.7.2, исправление осадков, сортировка прозрачности,
  Java 21 ARM64, LWJGL 3, OpenGL 4.1 Core и нативный fullscreen macOS.

Это выпуск совместимости. Нового обещания прироста FPS нет. Контрольные суммы
и проверки патчей сохранены: неизвестный будущий клиент по-прежнему отклоняется
до применения обновления и может потребовать следующей версии порта.

## Обновление с 1.7.3 и более ранних версий

1. Нажмите «Проверить обновления» → «Скачать DMG» либо откройте
   [релиз 1.7.4](https://github.com/prilepv/mcgl-arm64/releases/tag/v1.7.4).
2. Закройте игру и лаунчер, откройте DMG и замените приложение в «Программах».
3. Запустите **1.7.4** и дождитесь подготовки клиента.

Установка обновления приложения ручная. Профиль игры, аккаунты, сохранённые
пароли и настройки находятся вне приложения и сохраняются. Удалять профиль
или переустанавливать Java не нужно. Файлы игры загружаются с зеркал MCGL отдельно.

## Проверка

Выпуск основан на **build 198**, принятой пользователем после игровой проверки.
Автоматически проверены все три официальных входа, обратимость преобразования,
отрицательные случаи, сортировка прозрачности и настоящая подготовка установщиком.
Проверены установка с официального сервера, повторная проверка без обновления
и отсутствие неразрешённых ссылок на методы и поля. Полные результаты —
в [TESTING.md](TESTING.md).

Нужны Apple Silicon (M1 и новее), macOS 14+, интернет и аккаунт MCGL.
Java встроена. Подпись ad-hoc, без Developer ID и нотариализации Apple;
SHA-256 не отменяет проверки macOS. [Безопасность и приватность](../SECURITY.md).
Ручная приёмка не гарантирует отсутствие ошибок во всех игровых сценах.
