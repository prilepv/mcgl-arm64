# Minecraft Galaxy ARM64 — Bootstrap 1.7.0

Неофициальный нативный порт для Apple Silicon, macOS 14 или новее.
Java 21 ARM64 встроена. Оригинальные игровые JAR и ресурсы не входят в пакет:
при первом запуске они загружаются с официальных зеркал Minecraft Galaxy.

## Главное в 1.7.0

- Java 21, LWJGL 3 и GLFW: обновлённые библиотеки, окно и ввод.
- Игровой рендер на OpenGL 4.1 Core, шейдерах и индексированной геометрии.
- Пакетная отрисовка мира и текста; исправлен расход и восстановление чанкового кэша.
- Нативный fullscreen macOS с отдельным Space, зелёной кнопкой и F11.
- Новая вкладка «Изменения» с краткой офлайн-историей 1.7.0 и 1.6.4–1.6.7.

Сохранены исходные игровой планировщик, порядок чанков, локальная прозрачность,
настройки и менеджер аккаунтов. Фиксированный прирост FPS не обещается.
Совместимый legacy-слой ещё существует; полное удаление и многопоточное
построение чанков не объявляются завершёнными.

## Установка и обновление

Откройте DMG и перенесите целое приложение в «Программы».
Перед заменой старой версии закройте игру и лаунчер. Профиль, аккаунты,
пароли и настройки находятся вне приложения и сохраняются.
Новый установщик обновит библиотеки и патчи; не удаляйте профиль игры.
Отдельная Java, Homebrew или Rosetta для запуска не нужны.

Подпись ad-hoc, без Developer ID и нотариализации Apple. DMG и контрольная сумма
не отменяют проверки macOS. Используйте штатное разрешение для конкретного
приложения, если доверяете источнику; не отключайте защиту системы целиком.
При невозможности запуска сообщите точный текст ошибки.

Сохранение пароля опционально и выключено по умолчанию. Шифрование локальное,
ключ находится рядом; это не защита от программ с доступом к вашим файлам.
Не передавайте папку Credentials и пользовательский профиль другим людям.
