Minecraft Galaxy ARM64 — установка

1. Перетащите Minecraft Galaxy ARM64.app на значок Applications («Программы»)
   в этом окне. Дождитесь окончания копирования.
2. Извлеките образ диска через Finder.
3. Откройте Minecraft Galaxy ARM64 из папки «Программы».
4. Введите данные учётной записи MCGL и дождитесь загрузки клиента.
   ARM64- и графические патчи применяются автоматически.

Нужен Mac с Apple Silicon и macOS 14 или новее, а также интернет для первой
установки. Java уже находится внутри приложения. Устанавливать системную
Java, Homebrew или Rosetta не нужно.

Этот DMG содержит ту же сборку приложения, что и ZIP. Упаковка в DMG не
добавляет Developer ID или нотариализацию Apple. Текущая сборка подписана
локально (ad-hoc), поэтому macOS может заблокировать первый запуск.

Если macOS сообщает о непроверенном разработчике, сначала убедитесь,
что получили файл от доверенного источника и он не изменён. Для такого
приложения Apple предусматривает отдельное разрешение в «Системные настройки
→ Конфиденциальность и безопасность». Не отключайте защиту macOS целиком.
Предупреждение о вредоносном коде нельзя считать обычным запросом разрешения.
Справка: https://support.apple.com/102445

Если видите общее «Не удаётся открыть программу», сохраните точный текст
ошибки и сообщите версию macOS и сборки. Это сообщение само по себе не
указывает причину. Переустановка Java здесь не является решением.

Полное описание сборки и лицензии компонентов — в папке «Документация».
